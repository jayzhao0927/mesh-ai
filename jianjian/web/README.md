# 见见 H5 体验

暖绒 Rivet：暖奶油底、品红到橙渐变、手写点缀与拍立得卡片。聊天为主，只保留搭桥入口；没有常驻推荐栏或画像页。

```bash
npm ci
API_ORIGIN=http://localhost:8080 npm run dev
# /try：完整本地样例体验，不调后端，不发短信，不连接其他用户
# /：真实 Fastify API 联调，开发手机号登录
npm run typecheck
npm run build
```

样例路径：登录 → 城市/年龄/性别（可跳过）→ 两种关系目标及现有规则建档 → 随机预写小剧场 → 单张推荐样例 → 感兴趣 → 使用明确的体验控件模拟 mutual → 样例预约/进房。普通用户页面不会出现模拟对方表态的控件。

小剧场来自预写样例库，随机选择场景，没有调用 DeepSeek，不是对某位用户的真实预测。示例明确标注 AI 推演样例；不写入实际 p_mutual，不更改待确认的模拟权重。等待时间可用仅样例模式的控件快进，真实后端等待状态接口未接通。

真实模式仍走原 API 路径：资料写入 stated，聊天支持“看看我的资料”“把城市改成杭州”“删除年龄”“叫你小暖”；不存在独立画像页。现居、年龄、性别目前是私有资料补充字段，当前匹配模型尚未按这些字段硬过滤，不能声称已经实现年龄/性别/城市偏好匹配。自然语言画像抽取仍待后端任务 2。

推荐卡和理由再次过滤 Unicode 十进制数字、只展示允许字段；按 created_at 中性过期并关闭表态按钮。不展示他人的选择或已读。真实预约/进房有 API 调用，但不依据凭证字符串宣称已开通真实视频；TRTC 尚为 stub。真实推荐已有真实 PostgreSQL 与 p_mutual 分值落库验收，前端没有用样例覆盖真实接口失败。
